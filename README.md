## 🚀 Featured Work

### 📱 [RetailPilot](https://github.com/chinmaygit-lab/retailpilot)

Offline-first Android POS and inventory management system built with
**Kotlin, Jetpack Compose, Room and Hilt**, featuring sales processing,
stock-batch tracking, purchasing, analytics, barcode/OCR workflows,
database migrations and automated testing.

### 🛡️ [Anomaly Detection Model](https://github.com/chinmaygit-lab/Anomaly-Detection-Model)

Hybrid anomaly-detection pipeline combining **Transformer-VAE**
representations with **Isolation Forest, One-Class SVM and Local Outlier
Factor**, with attention-based score fusion.

### 🧠 [Social Saver Cognitive Engine](https://github.com/chinmaygit-lab/social-saver-cognitive-engine)

AI-powered cognitive engine for organizing, searching, scoring and
resurfacing saved URLs, notes and unstructured content using
**FastAPI, Streamlit and SQLite**.

### ⚙️ eSim Automated Tool Manager

Compatibility-aware Python CLI system for discovering, validating,
updating and managing external eSim toolchains with isolated execution,
version intelligence and workflow-aware tool selection.
